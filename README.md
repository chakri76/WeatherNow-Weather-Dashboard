# 🌦️ WeatherNow – Real-Time Weather Dashboard

A responsive and interactive Weather Dashboard built using **HTML, CSS, and JavaScript**. It fetches real-time weather information from the Open-Meteo REST API based on the city entered by the user.

## 🚀 Features

- 🌍 Search weather by city name.
- 🌡️ Display current temperature in Celsius.
- 💧 Show humidity percentage.
- 💨 Display wind speed.
- 🌧️ Show precipitation information.
- ☀️ Display weather conditions with dynamic icons.
- 🌙 Support day and night weather icons.
- ⚡ Fetch real-time weather data using Fetch API.
- 🔄 Handle asynchronous requests using Async/Await.
- 🛡️ Error handling for invalid cities and network failures.
- 📱 Responsive design for mobile and desktop screens.

## ⚙️ How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/WeatherNow-Weather-Dashboard.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Alternatively, use the Live Server extension in VS Code.

5. Enter a city name in the search box.

6. Click the Search button to view the current weather.

## 🌐 API Used

This project uses the **Open-Meteo API**.

- Weather API: https://api.open-meteo.com/v1/forecast
- Geocoding API: https://geocoding-api.open-meteo.com/v1/search
- Documentation: https://open-meteo.com/

No API key is required for non-commercial use.
